Remote Desktop

Мишка й клавіатура ноутбука керуватимуть комп'ютером. Панель з додатковими кнопками з'являється, якщо підвести мишку до верхнього краю екрана.

Зображення

Клавіші ноутбука передаються як є, розкладку перемикає комп'ютер (Alt+Shift або Win+Пробіл). Win, Alt+Tab і Ctrl+Alt+Del перехоплює система ноутбука — для перших двох є кнопки на панелі.
